# PROMPTS & PROJECTS by Juan Jaramillo

A personal knowledge base of **90+ production-ready AI system prompts** (13 numbered categories),
plus automation scripts, JSON payloads, and small utility projects. Prompts follow a consistent
structure (role → capabilities → instructions → examples) with `CAPS` / `%VARIABLE%` placeholders.

## Directory Structure

| Path                         | Contents                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------ |
| [`prompts/`](./prompts/)     | 13 categorized prompt libraries (see [`PROMPTS_INDEX.md`](./PROMPTS_INDEX.md)) |
| [`documents/`](./documents/) | Automation scripts, docs, and content files                                    |
| [`json/`](./json/)           | JSON payloads, schemas, and API configurations                                 |
| [`projects/`](./projects/)   | Standalone utility projects                                                    |
| [`scripts/`](./scripts/)     | Repository automation helpers                                                  |
