# Prompts Library

Curated AI system prompts organized into 13 numbered categories:

- `01-email-marketing/` — Email campaign generation (ActiveCampaign, EmailGenius)
- `02-topfinanzas-content/` — TopFinanzas content flows (Quiz, Review, Recommender)
- `03-social-media/` — LinkedIn posting, community management, social media
- `04-talent-assisto/` — TalentAssisto HR automation
- `05-seo-content/` — SEO content and optimizer prompts
- `06-courses-education/` — Course and education material generation
- `07-development-coding/` — Dev, coding, and agentic-workflow prompts
- `08-ecommerce-dropshipping/` — E-commerce / dropshipping sales agents
- `09-business-proposals/` — Proposal and consulting prompts
- `10-utilities-assistants/` — General assistants (Milton, Parcero, and more)
- `11-landing-pages/` — Landing page and maker prompts
- `12-templates-system/` — Reusable prompt templates
- `13-job-seeking-prompts/` — Job-search automation workspace (agent files, skills, scripts)
