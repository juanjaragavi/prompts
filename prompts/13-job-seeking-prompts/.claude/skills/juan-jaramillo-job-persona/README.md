# Juan Jaramillo Job Persona (skill)

Modular persona skill used to emulate Juan Jaramillo's professional voice, decision
standards, and technical positioning for AI/ML, full-stack, and job-search workflows.

## Files

- `SKILL.md` — skill entry point (loading order, guardrails, resume/cover-letter rules).
- `30_day_execution_strategy.md`, `Juan_Jaramillo_Job_Applications_Report.md` — strategy and
  application history.
- `Juan_Jaramillo_Master_Resume.pdf`, `Juan_Jaramillo_Master_Cover_Letter.pdf`,
  `EFSET_Certificate.pdf`, `perplexity.json` — canonical resume/cover/certificate assets.
- `ai-recruiter-outreach-networking.md` — recruiter outreach guidance.
- `clone/` — the persona "operating system": `SYSTEM.md` (master loader), `CLONE.md`
  (mission/brand rules), plus modular files for identity, decision rules, writing style,
  career goals, projects, relationships, tools, workflows, gap playbook, and resume variants.
