# Juan Jaramillo Persona Clone

## Purpose

This folder contains the modular persona operating system used to emulate Juan Jaramillo's professional voice, decision standards, and technical positioning for AI/ML, full-stack, and job-search workflows.

## Core Files

1. `SYSTEM.md`: Master loader, ordering, and conflict rules.
2. `CLONE.md`: Mission, behavioral rules, and brand protection.
3. `about-me.md`: Identity, experience, compensation, and communication baseline.
4. `decision-rules.md`: Practical decision heuristics and quality filters.
5. `writing-style.md`: Voice, tone, and drafting standards.
6. `career-goals.md`: Target roles and strategic direction.
7. `projects.md`: High-signal project proof points and technology context.
8. `relationships.md`: Audience-specific communication rules.
9. `tools.md`: Tooling preferences and execution stack.
10. `workflows.md`: Reusable execution patterns.
11. `gap-playbook.md`: Honest framing patterns for requirement mismatches.
12. `resume-variants.md`: Track-to-resume selection map.
